# הגדרת משתמש מנהל נפרד — הוראות (פעם אחת לכל פרויקט)

**מה זה נותן:** המדריכים ממשיכים להיכנס עם הסיסמה המשותפת (0509). רק מי שמחובר כ"מנהל" — עם סיסמה שרק הוא יודע — יכול להוסיף ולמחוק ילדים, לאפס לוחות, לערוך בונוסים ותורנויות, ולבחור חללית ועו״סית לכל ילד. השרת עצמו מסרב לכל אחד אחר. בנוסף, רק שתי כתובות המייל של הצוות והמנהל מקבלות גישה — גם מי שיצליח להירשם לא יראה כלום.

## קודם בפרויקט הבדיקות (כדי שאבדוק)
1. **Authentication ← Users ← Add user ← Create new user**
   - Email: `manager@merkaz-cherum.local`
   - Password: סיסמה לבדיקות בלבד (כמו שעשית עם סיסמת הבדיקות). שלח לי אותה בצ'אט כדי שאוכל להריץ בדיקות.
   - לסמן **Auto Confirm User** ← Create user.
2. **SQL Editor ← New query ← הדבקה של `supabase/roles.sql` ← Run.** (אני אעתיק אותו ללוח כשתגיד.)
3. **Authentication ← Sign In / Providers ← Email ← לכבות Allow new users to sign up ← Save.**
4. תגיד לי "הרצתי", ואני מוודא שהכול עובד: ביקורת של מה שהמדריך לא יכול ומה שהמנהל יכול.

## אחר כך בפרויקט החי
אותם שלושה צעדים, עם **הסיסמה האמיתית של המנהל** (אותה לא שולחים לי). **חשוב על הסדר:**
1. קודם מכין את משתמש המנהל (צעד 1) ומכבה את ההרשמה (צעד 3).
2. מריץ את `roles.sql` (צעד 2) **ממש לפני** שאני מעלה את הגרסה החדשה, כי מרגע שרץ, מסך הניהול של הגרסה הישנה (עריכת ילדים, רשימות וחלליות) לא יצליח לשמור. העבודה היומיומית של המדריכים (כוכבים, צעדים, גריעות) ממשיכה כרגיל.
3. תגיד לי "הרצתי בחי" ואז "תעלה", ואני מדליק את מצב המנהל בגרסה החדשה ומעלה.
